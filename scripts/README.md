# Scripts

Utility scripts for the repository. None of these are part of the shipped product; they are developer tooling and one-off helpers.

| Script | Description |
| ------ | ----------- |
| `demo-runner.mjs` | Runs the demo flow end-to-end for manual verification and demos. |

Run a script with `Node.js` (e.g. `node scripts/demo-runner.mjs`).
